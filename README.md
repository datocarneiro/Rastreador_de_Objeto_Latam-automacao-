Documentação do Código
 
> <h3>✅  projeto validado com a versão do 🐍python 3.14 </h3>


Durante a instalação:

☑ Add Python to PATH


criar ambiente virtual (sugestão passara aversão especificada do python)

```bash
    python -3.14 -m venv venv
        # ou
    py -3.14 -m venv venv
```
Ativar ambiente virtual
```bash
    source venv/Scripts/activate
```
Atualizar pip
```bash
    python -m pip install --upgrade pip 
```

Instalar dependencias definidas
```bash
    pip install -r requirements.txt
```


executar programa
```bash
    python Dato_Latam.py
```

Abrir no navegador
```bash
    http://localhost:8080
```
